# AURA Detailing — демо-сайт детейлинг-студии

Одностраничный статический сайт. Название, цены, отзывы и контакты условные — замените их в `index.html`.

- `index.html` — вся страница и тексты.
- `assets/css/styles.css`, `assets/js/main.js` — оформление, меню, слайдер, форма-заглушка.
- `tests/site.test.mjs` — тесты в браузере (Playwright): `node tests/site.test.mjs`.
- Источники фото — в `CREDITS.md`.

Прежняя версия (сайт школы) сохранена в ветке `school-site`.
