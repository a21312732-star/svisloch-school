# Сайт Свислочской средней школы им. А. Г. Червякова

Статический сайт ГУО «Свислочская средняя школа им. А. Г. Червякова» (г. п. Свислочь, Пуховичский район).

- `build.mjs` — все тексты и шаблон страниц. После правок: `node build.mjs`.
- `images.mjs` — какие фотографии где показываются.
- `assets/` — стили, скрипты, изображения (авторы фото — в `credits.html`).
- `tests/site.test.mjs` — тесты в браузере (Playwright): `node tests/site.test.mjs`.

Сведения взяты с официального сайта школы https://svisloch.pukhovichi-asveta.gov.by/ и открытых источников.
